Code for Topological Hidden Semi-Markov Models

WARNING: All code is temporary and open to changes. Please keep up to date with the most recent version. 

Contents: All functions for simulating THSMM data, creating an embedded THSMM, and fitting. Plus a test suite. No OSA data is in this repository and will NOT be added. 

Tests (tests/):
1. testsMaster.R is the test script used for paper results. 
2. paperSims.R is a file containing a huge test suite of results. Its THMMs are fitted with the funHMM package, which must be installed. 

Vignettes: 
1. getting-started.R is a file to familiarize yourself with the package.
